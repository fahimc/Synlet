# Original conversation artifacts

These four files are preserved byte-for-byte, with their original filenames and
working title (Collective). They are retained for provenance, not as competing
current build instructions. Use the Synlet/SOMA files at the repository root and
under `docs/` for new development.

- [Original architecture HTML](originals/collective-llm-architecture.html)
- [Architecture and Codex handbook v0.2](originals/collective-llm-architecture-v0.2.html)
- [Original Codex handoff ZIP](originals/collective-codex-handoff-v0.2.zip)
- [Original optional Gitea publishing ZIP](originals/collective-gitea-publish.zip)

The Gitea archive is optional historical tooling. It is not required to work with
this GitHub repository and has not been run here. Its status statements describe
preparation of that earlier package, not the current GitHub upload.

Checksums for the originals are included in the root `HANDOFF_FILES.sha256`.
