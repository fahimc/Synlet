# Browser check v1

Use the dedicated Playwright profile, DOM-first accessible targeting and an explicit
domain allow-list. Stop at authentication, CAPTCHA or uncertain consequential action.

Start with generic live search when the user has not supplied a URL. Search results are
discovery evidence: inspect a relevant result when the requested facts are not already
present. If direct navigation fails, use search and another relevant source rather than
repeating the same URL or answering from a directory listing. Finish only when a
successful browser observation contains the content the user requested.
